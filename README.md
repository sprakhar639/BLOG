# Blog API

A full-stack blog application built with React, Node.js, Express, and MongoDB.

Users can register and log in, create and view blogs, and manage their own blogs. 
Users can edit or delete only the blogs they own.

## Features

- User registration and login
- User logout
- User profile
- Create blogs
- View blogs
- Edit blogs
- Delete blogs
- Blog ownership authorization

## Tech Stack

### Frontend
- React
- React Router
- Axios
- Vite

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
